# Резервное копирование и восстановление Lounge OS

## Что сохраняется

Резервная копия содержит только данные Lounge OS — ключи LocalStorage с префиксом `lounge_os_`. Данные других сайтов и приложений не читаются и не удаляются. Локальные снимки не вкладываются в backup, поэтому файл не растёт рекурсивно.

Файл содержит версию формата, дату создания, версию Lounge OS, данные и checksum. Checksum помогает обнаружить случайное повреждение или изменение файла.

## Где хранятся данные

Рабочие данные и локальные снимки находятся в LocalStorage текущего профиля браузера. Снимки хранятся под ключом `lounge_os_local_snapshots`; система оставляет не более 10 последних.

Скачанный JSON-файл сохраняется в папку загрузок браузера или в выбранное пользователем место. Это единственная копия, которая не зависит от сохранности браузерного профиля.

## Как скачать backup

Откройте «Настройки» → «Резервное копирование и восстановление» и нажмите «Скачать резервную копию». Полученный файл будет называться примерно `lounge-os-backup-2026-08-04-18-30.json`.

## Как восстановить данные

1. Откройте экран «Настройки».
2. Выберите режим восстановления.
3. Нажмите «Восстановить из файла» и выберите JSON-файл Lounge OS.
4. Подтвердите операцию.

Перед импортом Lounge OS автоматически создаёт защитный локальный снимок текущего состояния.

### Replace и merge

- «Полностью заменить данные» (`replace`) удаляет текущие ключи Lounge OS, кроме локальных снимков, и записывает содержимое backup. Чужие ключи LocalStorage остаются нетронутыми.
- «Объединить с текущими» (`merge`) объединяет массивы объектов по полю `id`. При совпадении `id` версия из backup имеет приоритет. Остальные типы значений заменяются версией из backup.

## Локальные снимки

Локальный снимок — быстрое сохранение текущего состояния внутри того же браузера. Он создаётся вручную и автоматически перед восстановлением. Перед возвратом к старому снимку система дополнительно сохраняет текущее состояние, не запуская рекурсивную цепочку восстановлений.

Локальные снимки удобны для отмены ошибки, но не заменяют скачанный backup: они исчезнут вместе с данными браузера.

## Аварийный порядок действий

### Приложение открылось без данных

Не создавайте новые записи. Откройте «Настройки» и проверьте список локальных снимков. Восстановите последний снимок с датой до исчезновения данных. Если снимков нет, импортируйте последний скачанный JSON.

### Импортирован неправильный файл

После каждого импорта создаётся safety snapshot. Откройте локальные снимки и восстановите запись с причиной «Перед восстановлением backup».

### Данные случайно удалены

Восстановите последний локальный снимок. Если нужного состояния в списке нет, используйте скачанный JSON-файл.

### LocalStorage повреждён

Попробуйте восстановить последний корректный снимок через `emergencyRestoreLatestSnapshot()` из `core/backup.js`. Если интерфейс доступен, предпочтительнее выбрать снимок вручную. При отсутствии корректных снимков очистите только данные Lounge OS и импортируйте проверенный JSON.

### Перенос на другой компьютер

На старом компьютере скачайте backup. Передайте JSON безопасным способом, откройте Lounge OS в браузере на новом компьютере и выполните восстановление. Для полного переноса используйте режим replace.

## Ограничения

LocalStorage не синхронизируется между устройствами и браузерами. Он может быть очищен пользователем, браузером, корпоративной политикой или инструментами очистки. Объём хранилища ограничен браузером. Checksum защищает от случайного повреждения, но не является криптографической подписью и не доказывает подлинность файла.

Если компьютер или профиль браузера утрачен, восстановление возможно только из заранее скачанного JSON-файла.

Рекомендуется хранить минимум две скачанные копии в разных местах, например на внешнем носителе и в защищённом облачном хранилище.
