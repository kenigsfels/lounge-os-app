# SYLON Desktop Preview

Desktop Preview — переносимая тестовая версия SYLON для ежедневной работы на Windows.

## Где находятся данные

- сотрудники, задачи, настройки и локальный кэш: `%APPDATA%\sylon-os`;
- рабочий график и внешние файлы: `C:\Users\User\Desktop\SYLON\SYLON OS\data`;
- файлы Preview: `C:\Users\User\Desktop\SYLON Preview`.

Обновление Preview заменяет только исполняемый файл в папке Preview. Оба каталога данных остаются
на месте. Удаление самого Preview-файла также не удаляет данные.

## Ежедневная работа

Запускайте приложение ярлыком `SYLON` на рабочем столе. Для ручной проверки или переноса графика
используйте ярлык `SYLON Data`.

Перед крупными экспериментами создавайте JSON backup на экране «Настройки». Встроенные safety snapshots
продолжают работать независимо от переносимой сборки.

## Обновление

Новая итерация собирается командой `npm run desktop:preview`. После проверки новый exe можно положить
в `C:\Users\User\Desktop\SYLON Preview`, сохранив имя `SYLON Preview.exe`. Ярлык менять не потребуется.

## Статус

Это Preview-сборка: визуал и поведение будут меняться небольшими утверждёнными итерациями. Форматы данных
и совместимость backup меняются только через отдельные безопасные миграции.
