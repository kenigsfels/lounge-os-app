SYLON DESKTOP PREVIEW

Запуск
  Используйте ярлык «SYLON» на рабочем столе.

Рабочие данные
  Сотрудники, задачи и настройки: %APPDATA%\sylon-os
  График и внешние файлы: C:\Users\User\Desktop\SYLON\SYLON OS\data

Обновление
  Новая версия заменяет только файл SYLON Preview.exe в этой папке.
  Ярлык и рабочие данные остаются на месте.

Безопасность
  Перед крупными экспериментами создавайте JSON backup в разделе «Настройки».
  Не храните рабочие данные внутри папки Preview.

Статус
  Это тестовая Preview-версия. Интерфейс и функции будут меняться небольшими
  утверждёнными итерациями без удаления существующих данных.
