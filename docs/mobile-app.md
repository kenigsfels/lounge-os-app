# Мобильное приложение LoungeOS

Телефонная версия распространяется как PWA из той же production-сборки, что и
GitHub Pages. Это сохраняет единый интерфейс, LocalStorage-кэш и Supabase-клиент
для компьютера, Android и iPhone.

## Установка на Android

1. Откройте `https://kenigsfels.github.io/lounge-os-app/` в Chrome.
2. Перейдите в «Настройки» → «Мобильное приложение».
3. Нажмите «Установить LoungeOS». Если кнопка ещё не появилась, используйте
   меню Chrome → «Установить приложение» или «Добавить на главный экран».

## Установка на iPhone

1. Откройте ссылку в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой», затем подтвердите добавление.

После установки LoungeOS запускается с иконки в отдельном полноэкранном окне.
Service worker хранит оболочку и уже загруженные статические ресурсы; локальные
данные приложения остаются в хранилище телефона. Первый запуск и получение
новых облачных данных требуют интернет.

## Синхронизация

Мобильная оболочка не создаёт отдельную базу. После входа по magic link она
использует тот же Supabase-проект и RLS-политики, что браузер и компьютер.
Пока вход не выполнен, изменения остаются локальными только на этом телефоне.
