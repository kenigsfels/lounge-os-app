# Changelog

## [0.6.0] — 2026-08-10

### Added

- облачное хранение графика смен в Supabase на уровне заведения;
- RLS-политики чтения для участников и записи для владельцев/администраторов;
- offline-first выбор более свежего локального или облачного графика;
- автоматическая синхронизация графика при входе, ручной синхронизации,
  открытии Dashboard и экрана графика;
- четыре регрессионные проверки выбора версии графика.

### Changed

- локальный график desktop-приложения кэшируется в LocalStorage и остаётся
  доступным при временной недоступности Supabase;
- версия приложения и метаданных backup обновлена до `0.6.0`.

## [0.5.1] — 2026-08-10

### Fixed

- callback magic link теперь корректно сохраняет каталог `/lounge-os-app/` на
  GitHub Pages при относительном `base: './'` в Vite;
- добавлены регрессионные тесты callback URL для GitHub Pages, локального Vite
  и абсолютного base path.

### Changed

- версия приложения и метаданных backup обновлена до `0.5.1`.

## [0.5.0] — 2026-08-10

### Added

- полноценный недельный календарь смен с навигацией по будущим неделям;
- безопасный read-only мост Electron к локальному графику LoungeOS;
- ближайшие смены из общего графика на Dashboard;
- отображение мастеров, администраторов, времени и заметок дня;
- тесты нормализации и выбора текущей недели.

### Changed

- desktop-приложение читает актуальный график из локального файла
  `schedule/app-schedule.json`, поэтому обновление данных не требует пересборки;
- версия приложения и формата backup обновлена до `0.5.0`.

## [0.4.0] — 2026-08-10

### Added

- самостоятельная Electron-оболочка для Windows;
- NSIS-установщик, ярлыки рабочего стола и меню «Пуск»;
- протокол `loungeos://open/<раздел>` для переходов из Rainmeter;
- отдельный значок LoungeOS и команды разработки/сборки desktop-версии.

### Security

- включены изоляция контекста, sandbox и запрет Node.js в интерфейсе;
- внешние ссылки открываются системным браузером, неизвестные переходы и
  запросы разрешений блокируются;
- добавлена Content Security Policy для локальной сборки и Supabase.

### Changed

- версия приложения и формата backup обновлена до `0.4.0`.

## [0.3.0] — 2026-08-10

### Added

- Vite-сборка с хэшированными production-ресурсами;
- клиент Supabase Auth и offline-first синхронизация сотрудников;
- SQL-миграция для заведений, участников и сотрудников с RLS;
- вход по magic link и управление облаком в настройках;
- GitHub Actions для тестирования, сборки и публикации GitHub Pages.

### Changed

- LocalStorage остаётся локальным кэшем и резервным режимом при недоступном
  облаке;
- версия приложения и формата backup обновлена до `0.3.0`.

## [0.2.1] — 2026-08-09

### Added

- рабочий экран сотрудников с добавлением, редактированием и удалением;
- показатели команды на Dashboard;
- команды `npm start` и `npm test`;
- подготовка статической версии для GitHub Pages.

### Changed

- демонстрационные сотрудники обезличены;
- версия резервной копии синхронизирована с приложением.

## [0.2.0] — 2026-08-04
