# Changelog

## [0.2.1] — 2026-08-09

### Added

- рабочий экран сотрудников с добавлением, редактированием и удалением;
- показатели команды на Dashboard;
- команды `npm start` и `npm test`;
- подготовка статической версии для GitHub Pages.

### Changed

- демонстрационные сотрудники обезличены;
- версия резервной копии синхронизирована с приложением.

## [0.2.0] — 2026-08-04

### Added

- резервное копирование в JSON;
- восстановление replace/merge;
- локальные снимки;
- аварийное восстановление;
- интерфейс управления резервными копиями;
- тесты backup;
- ROADMAP и документация.

## [0.1.0] — 2026-08-04

### Added

- Dashboard;
- Dock;
- SPA-навигация;
- зелёно-золотая тема;
- компонентная архитектура;
- ядро сотрудников и LocalStorage.
