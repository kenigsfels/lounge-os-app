# Архитектура SYLON OS

## Общая схема

SYLON OS — модульное SPA без UI-фреймворка. `script.js` связывает hash-маршруты,
рендереры экранов и их функции очистки. Бизнес-данные и синхронизация находятся
в `core/`, переиспользуемый интерфейс — в `components/`, страницы — в `screens/`.

Новый экран `#dashboard` является пространственным Home-интерфейсом, но не
заменяет существующие разделы. Его кнопки вызывают тот же механизм `navigate`,
который используют Dock, системные ссылки и остальные экраны.

## SYLON Home

- `screens/home.js` собирает главную сцену и управляет её жизненным циклом.
- `components/sylon-core.js` лениво загружает Three.js и отвечает только за
  интерактивный SYLON Core.
- `core/sylon-state.js` хранит описание узлов и выбирает профиль качества.
- `core/command-router.js` преобразует локальные текстовые команды в маршруты.
- `components/contextual-card.js`, `assistant-input.js` и
  `fallback-navigation.js` остаются обычными DOM-компонентами.
- `styles/sylon-home.css`, `sylon-core.css` и `sylon-motion.css` изолируют
  визуальную систему главной от стилей рабочих экранов.

## Производительность и доступность

Three.js находится в отдельном динамическом чанке и загружается только на
главной. Число частиц, pixel ratio и детализация выбираются по возможностям
устройства, а после первого замера FPS качество может быть снижено. Скрытая
вкладка не рендерит сцену. `prefers-reduced-motion` отключает непрерывную
анимацию; отсутствие WebGL или ошибка загрузки Three.js включает CSS fallback.

При смене маршрута экран возвращает функцию очистки. Она снимает обработчики,
останавливает requestAnimationFrame и освобождает геометрию, материалы и WebGL
context. Клавиатурная навигация остаётся доступной через модули, Ctrl/Cmd+K и
скрытую нижнюю панель.

## Данные

Home только читает существующие данные сотрудников и графика. LocalStorage,
backup, Supabase, Electron IPC и модели данных не менялись. Поэтому возврат к
предыдущему интерфейсу возможен без миграции пользовательских данных.

## Проверки

`npm test` запускает прежние тесты данных и отдельный набор `tests/home.test.js`.
`npm run check` проверяет синтаксис новых точек входа, а `npm run build` —
production-сборку и динамический чанк Three.js.
